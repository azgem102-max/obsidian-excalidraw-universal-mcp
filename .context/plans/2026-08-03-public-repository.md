# خطة الريبو العام

## الهدف

يُرسل المستخدم الريبو إلى Claude أو Codex، فيقرأ التعليمات ويثبت النظام ويطلب إعادة تشغيل واحدة ثم يتحقق عبر `doctor.mjs`، دون إعادة اختبارات القبول التطويرية.

## المكونات

1. مدخل موحد: `START-HERE-AR.md` و`CLAUDE.md` و`AGENTS.md`.
2. مثبت متعدد الأنظمة والعملاء: `install.mjs`.
3. إصدارات رسمية مقفلة: `plugin-versions.json`.
4. جسر MCP محلي و59 أداة.
5. 17 سكربت تخطيط و15 احترافيًا.
6. فحص جاهزية غير هدّام: `doctor.mjs`.
7. وثائق عربية للتثبيت والاستخدام والبنية والأعطال والأمان.

## بوابة النشر

- نجاح `npm run check`.
- نجاح تثبيت offline وهمي وتنزيل الإصدارين الرسميين في Vault وهمي.
- نجاح جولة قبول حية لـ0.5.3 مع فحص الصور.
- فحص عدم وجود أسرار أو خطوط أو مسارات شخصية في الملفات المنشورة.
- إنشاء ريبو مستقل ودفعه فقط بعد اختيار المستخدم عامًا أو خاصًا.
