# حالة الحزمة

> آخر تحديث: 2026-08-04 — Codex

- الحزمة توفر خادم MCP محليًا موحدًا لـObsidian وExcalidraw باسم `excalidraw`.
- نسخة التطوير الحالية للجسر والخادم `0.6.0`، وعدد الأدوات 59.
- البيئة الحية: Obsidian 1.13.4، Excalidraw 2.25.3، Extras 0.0.15.
- المحتوى المثبت: 17 سكربت تخطيط أساسيًا و15 سكربتًا احترافيًا.
- `install.mjs` يثبت الإضافات والجسر والمحتوى ويضبط Claude/Codex ومشروع MCP.
- `doctor.mjs` يثبت جاهزية النسخ والإضافات واتصال الجسر الحي.
- نجحت فحوص المصدر والحزمة للإصدار `0.6.0`: ‏37/37، والاختبار الذاتي يثبت عرض 59 أداة.
- نجحت جولتا القبول الحي الأساسيتان 53/53 لكل جولة بعد إعادة تشغيل Obsidian.
- نجح اختبار الأدوات المكمل 11/11، بما فيه المسح والاستعادة والمشاركة الخارجية لرسم اصطناعي.
- نجحت 4 سكربتات احترافية قابلة للأتمتة؛ 9 تفاعلية و2 يعتمدان على مدخلات/أصول خارجية موثقة بوضوح ولا تُحسب ناجحة آليًا.
- أثبت التصدير SVG تضمين الخط المحلي الرابع بصيغة WOFF2 وظهور العربية، وراجعت عينات PNG بصريًا.
- نتائج الاختبار الكاملة في `ACCEPTANCE-TEST-MATRIX.md`، وخطة النشر في `.context/plans/2026-08-03-public-repository.md`.
- اجتازت نسخة النشر المستقلة فحص `npm run check`: ‏25/25 اختبارًا و59 أداة، ولم يُعثر على رموز وصول أو خطوط خاصة أو بيانات Vault.
- المستودع العام: `https://github.com/azgem102-max/obsidian-excalidraw-universal-mcp`.
- أُعيدت كتابة واجهة `README.md` بلغة عربية بسيطة وعنوان مباشر، مع قسم واضح ينسب النتيجة إلى Obsidian وExcalidraw for Obsidian وExtras ومكتبة السكربتات وExcalidraw core ومرجع MCP، بروابط مباشرة لكل مشروع.
- أصبح المثبّت يميز WSL عن Linux العادي: يكتب إعداد Claude Desktop باستخدام `node.exe` ومسارات Windows، ويرفض المسارات غير المشتركة، ويوفر `install-on-windows.ps1` للجلسات المنفصلة؛ تغطي ذلك 5 اختبارات جديدة.
- أضيف `setup-windows.cmd` للتثبيت بنقرتين: يختار المستخدم الـVault من نافذة، ويتجاوز عائق PowerShell، ويطلب الموافقة قبل تثبيت Node.js عند غيابه.
- راجعت حزمة تسليم Claude للإصدار `0.6.0` وطُبقت التحسينات مع إصلاح معرّفات العناصر والربط بين الأسهم والأشكال، وتمرير مسار Node، واكتشاف إعداد Claude في نسخ Windows المختلفة.
- نتائج القبول الحي المنشورة ما زالت تخص `0.5.3`؛ يلزم تثبيت `0.6.0` في Vault تجريبي وإعادة تشغيل Obsidian قبل اعتماد قبول حي جديد.
