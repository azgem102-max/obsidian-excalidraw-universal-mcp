# دليل نشر المستودع

الحزمة مصممة لتُنشر كمستودع مستقل. انسخ مجلد `obsidian-excalidraw-mcp` كاملًا إلى مستودع جديد من دون نقل ملفات الـVault أو إعدادات جهازك.

## ما الذي يجب أن يبقى في المستودع؟

- `START-HERE-AR.md` ليكون مدخل المستخدم الوحيد.
- `AGENTS.md` و`CLAUDE.md` حتى يفهم وكيل الذكاء الاصطناعي طريقة الإعداد والاستخدام.
- `install.mjs` و`doctor.mjs` والخادم والجسر.
- ملفات الإصدارات المقفلة والسكربتات والأدلة والاختبارات الساكنة.
- `LICENSE` و`THIRD_PARTY_NOTICES.md` لإيضاح تراخيص المكونات.

## ما الذي لا يُنشر؟

- مجلد الـVault أو محتواه.
- `.obsidian/plugins/*/data.json` لأنه قد يحتوي رمز الجسر المحلي.
- إعدادات Claude أو Codex الشخصية.
- ملفات خطوط يملكها المستخدم، ومنها خط «ثمانية».
- مجلدات الاختبارات المؤقتة والنسخ الاحتياطية والسجلات.

## فحص ما قبل النشر

من جذر المستودع شغّل:

```bash
npm run check
```

ثم نفّذ تثبيتًا معزولًا في Vault تجريبي أو اعتمد نتيجة الإصدار الموثقة. المستخدم النهائي لا يحتاج إلى اختبارات القبول الحية؛ يكفيه `doctor.mjs` بعد التثبيت وإعادة التشغيل.

## وصف مقترح للمستودع

> حزمة عربية محلية تربط Obsidian وExcalidraw مع Claude وCodex وأي عميل MCP، وتشمل مُثبّتًا موحدًا و59 أداة للرسم والملاحظات والتصدير والسكربتات، مع إعدادات قابلة للتكرار وفحص جاهزية سريع.

## أول إصدار

1. أنشئ مستودعًا عامًا أو خاصًا باسم مثل `obsidian-excalidraw-universal-mcp`.
2. اجعل `START-HERE-AR.md` أول رابط في `README.md`.
3. أنشئ إصدارًا يحمل رقم نسخة الجسر، مثل `v0.6.0`.
4. أدرج في ملاحظات الإصدار نسخ Obsidian والإضافات التي اختُبرت.
5. لا تعد المستخدم بتثبيت صامت لتطبيق Obsidian نفسه؛ الوكيل يطلب إذنه، أما بقية البيئة فيثبتها `install.mjs`.
