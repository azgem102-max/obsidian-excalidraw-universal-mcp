# كيف يقرأ الوكيل ويكتب ويرسم

بعد أن ينجح `doctor.mjs` يظهر خادم MCP واحد باسم `excalidraw`.

## الكتابة والتنظيم

- سرد الملاحظات والبحث في النص والخصائص.
- إنشاء ملاحظة عربية مع YAML frontmatter.
- تحديث جزء محدد بدل استبدال الملف كله.
- نقل الملاحظات وتنظيم المجلدات والحذف إلى السلة.
- قراءة الروابط الخلفية وبنية الـVault.
- ربط عنصر رسومي بملاحظة أو عنوان أو block، وتضمين النص المرجعي داخل الرسم.

## الرسم

- مستطيل: خطوة أو كيان أو بطاقة.
- بيضاوي: بداية/نهاية أو مفهوم ناعم.
- معيّن: قرار أو سؤال له فروع.
- خط: فصل أو علاقة بلا اتجاه.
- سهم مستقيم: انتقال مباشر.
- سهم منحني: تفرع أو عودة دون قطع العناصر.
- سهم بزوايا: عبور منظم بين المسارات والمناطق.
- إطار: صفحة أو شريحة أو نطاق مستقل.
- رسم حر: شرح يدوي أو إبراز بصري.

## دورة الجودة المطلوبة من الوكيل

1. `describe_scene` لفهم الرسم الحالي.
2. `snapshot_scene` قبل التغيير الكبير.
3. إنشاء دفعي للعناصر مع IDs واضحة.
4. محاذاة وتوزيع وتجميع وترتيب طبقات.
5. `get_canvas_screenshot` ومراجعة النص والتداخل والأسهم.
6. إصلاح العيوب ثم إعادة الصورة.
7. `save_drawing` وتصدير PNG/SVG عند الطلب.

## السكربتات

يكتشف `list_scripts` كل سكربت داخل مجلد Script Engine آليًا. يشغّل `run_script` السكربت داخل محرك Excalidraw الحقيقي، ويمكنه تمرير التحديد وإجابات `inputPrompt` و`suggester`. السكربتات ذات Sidepanel أو FloatingModal تبقى تفاعلية بطبيعتها؛ يستخدم الوكيل أدوات MCP الأصلية المقابلة عندما يكون المطلوب آليًا بالكامل.

## التوافق

- Claude Code وClaude Desktop وCodex والعملاء المحليون الذين يدعمون stdio MCP: مدعومون مباشرة.
- ChatGPT على الويب لا يستطيع الوصول إلى `127.0.0.1` أو ملفات جهازك مباشرة. لا تعرّض الـVault للإنترنت؛ استخدم Codex/عميل سطح مكتب محلي أو نفّذ بوابة بعزل ومصادقة صريحين إن كان ذلك مطلبًا مؤسسيًا.
