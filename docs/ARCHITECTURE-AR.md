# بنية النظام

```text
Claude / Codex / MCP Client
          │ stdio
          ▼
server.mjs — خادم باسم excalidraw
          │ HTTP محلي + Bearer token
          ▼
127.0.0.1:27125
          │
          ▼
Obsidian MCP Bridge
   ├─ Vault API للملاحظات والروابط
   ├─ ExcalidrawAutomate للعناصر والتصدير
   ├─ Script Engine للسكربتات
   └─ Excalidraw Extras لـ Mermaid وLaTeX
```

لا يقرأ عميل MCP الرمز من الريبو؛ تنشئه الإضافة عند التشغيل الأول داخل `data.json` المحلي. الخادم يقرأه وقت الاتصال. الجسر يستمع على loopback فقط، وكل العمليات متسلسلة ولها مهلة.

## لماذا خادم واحد؟

لأن الوكيل يحتاج فهم الملاحظة والرسم معًا. فصل Obsidian عن Excalidraw يجعل الروابط والتضمينات والملفات المضمنة والحفظ مسؤولية العميل. الخادم الموحد يخفي هذه التفاصيل ويعيد أدوات مفهومة ومتسقة.

## ما لا يُرفع إلى Git

- الـVault الشخصي وملاحظاته.
- رمز الجسر وملفات الإعداد الشخصية.
- خطوط محلية بلا ترخيص توزيع.
- صور وملفات قبول مؤقتة.
